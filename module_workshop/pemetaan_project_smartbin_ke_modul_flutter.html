Ringkasan eksekutif

Project SmartBIN menggabungkan hampir semua kelompok materi yang menjadi bekal project akhir pada BKPM: workflow Git, lingkungan Flutter, desain UI dan layout, list, modularisasi widget, navigasi, penyimpanan preferensi, JSON, serta komunikasi HTTP. Implementasinya memperluas latihan mobile dengan backend REST dan database server.

Kesimpulan singkat:

SmartBIN bukan hanya contoh tampilan Flutter. Kode aplikasi menunjukkan penerapan materi workshop dari UI hingga HTTP, sedangkan backend NestJS, MySQL, autentikasi token, dan model bisnis SmartBIN merupakan materi pengayaan. Beberapa bahasan BKPM—khususnya GPS, sensor ponsel, SQLite, pengelolaan file, dan URL Launcher—belum diwujudkan secara langsung.

Prioritas yang disarankan:

Untuk menunjukkan keterkaitan modul, prioritaskan bukti Acara 1–4, 9–24, 29–32, 37–44, dan 45–56. Untuk pembahasan jujur, sebutkan Acara 25–28 dan 33–36 sebagai belum diterapkan secara langsung, bukan menyamakan MySQL server dengan SQLite atau mock NFC dengan akses sensor asli.

Jalur presentasi: tunjukkan konsep modul lewat satu alur

  1. Workflow Git: tunjukkan repository, branch, dan riwayat commit sebagai bukti pengelolaan source code.
  2. Widget/material/layout: buka login, beranda, riwayat, dan mode tema; jelaskan widget tree serta komponen bersama.
  3. List dan modularisasi: buka daftar riwayat/mesin; telusuri screen → tile/widget → model.
  4. Navigasi: buka detail setoran dari list dan pindah tab menggunakan router.
  5. Shared Preferences: ubah tema atau onboarding lalu tunjukkan nilai preferensi tersimpan.
  6. JSON & HTTP: tunjukkan request API, header auth, JSON parsing, dan pemetaan respons ke model Dart.
  7. Project final: tunjukkan PRD, test alur, backend, ERD, serta jelaskan kebutuhan bisnis SmartBIN.
  8. Materi yang belum ada: jelaskan batasan SQLite, GPS/sensor asli, NFC mock, push FCM dan MQTT tanpa mengklaim sudah selesai.
Untuk demo API publik:

Gunakan akun pengujian yang memang terdaftar pada server. Jangan tampilkan kata sandi, token, UID KTM mentah, atau data pribadi mahasiswa di layar presentasi maupun dokumentasi.
